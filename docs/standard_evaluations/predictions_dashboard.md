## # [Workmate Predictions Dashboard](https://www.workmate.nonproftinnovations.io/superuser/predictions)
After logging in, if you're a Superuser or Area Manager, you will be redirected to the Predictions Dashboard. This is the place where you can analyse the predicted performance basing on various data collected in the Standard Evaluation Surveys


### 1. Aggregated Smart Filters

You can be able to filter Aggregated Predictions by Cohort, Cycle, Region, District, Cluster and Evaluation.  
You can also download your data for further analysis by using the "Download CSV" button.
